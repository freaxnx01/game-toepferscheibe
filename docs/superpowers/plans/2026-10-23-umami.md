# Umami-Statistik Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Page views plus a `game_start` event in self-hosted Umami, a privacy section and link, and release 0.2.0 (#12).

**Architecture:** The same pattern as game-tschau-sepp: an `<!-- umami:start/end -->` block before `</head>` loads `g.js` and a local `analytics.js` (`window.gameAnalytics`). `startNew` calls `gameAnalytics.track` behind a guard.

**Tech Stack:** Buildless static page (dc document), Playwright e2e (Python), node:test.

**Spec:** Issue #12 body; hub spec `~/repos/github/freaxnx01/public/freaxnx01.github.io/docs/superpowers/specs/2026-10-10-umami-rollout-design.md` (sections "Stage 1" and "Stage 2"). The user decided:
- `game_start` fires **only** on „Ton auf die Scheibe legen“ (`startNew`). It does not fire on „Weiter töpfern“ (`loadWork`), on page load, on navigation, or on back-to-work. Properties: `{game: 'toepferscheibe'}` only, with no `mode`.
- Minor release **0.2.0**: `version.js`, a CHANGELOG section that also back-fills #6, #9, #10 and #11 (all merged after 0.1.0), and tag `v0.2.0` (the tag is created at merge time, not in the branch).
- The Umami website already exists (created by the controller): id **`fb5c286b-6790-4b29-b8fc-30d18fd9b218`**, domain `github.freaxnx01.ch`.

## Global Constraints

- Use Test-Driven Development for every task: write a failing test first, watch it fail, implement minimally to pass, verify green.
- Run e2e under `systemd-run --user --scope -q -p MemoryMax=2G -p MemorySwapMax=0`.
- Copy `analytics.js` byte for byte from `~/repos/github/freaxnx01/public/game-tschau-sepp/analytics.js`.
- Snippet block, verbatim apart from the id:
  ```html
  <!-- umami:start -->
  <!-- Umami analytics (self-hosted, server in Germany). data-domains keeps dev/local runs out of the stats. -->
  <script defer src="https://stats.freaxnx01.ch/g.js" data-website-id="fb5c286b-6790-4b29-b8fc-30d18fd9b218" data-domains="github.freaxnx01.ch"></script>
  <script src="./analytics.js"></script>
  <!-- umami:end -->
  ```
- The privacy link is **not** in `#game-nav`. Use `target="_blank" rel="noopener"` and the href `https://github.com/freaxnx01/game-toepferscheibe#datenschutz--privacy`.
- German copy uses real umlauts. The game UI addresses the player with „Sie“.

## Review Focus

- e2e runs on 127.0.0.1. `data-domains` keeps those runs out of the stats, and `g.js` must not break the suite when it is offline or blocked. Tests should route/block `stats.freaxnx01.ch` so they never hit the real server.
- `track` must not fire on `loadWork` („Weiter töpfern“), `backToWork`, or a reload.
- The game must work unchanged when `window.gameAnalytics` is undefined (`analytics.js` failed to load).
